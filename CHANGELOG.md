# Changelog

All notable changes to moss are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/). Exit codes and JSON output are contracts: stable within
a major version, additions only.

## [Unreleased]

### Added

The v1 command surface, on macOS, Linux and Windows, against Kopia 0.23.x.

- `init`: repository create or connect for filesystem and S3-compatible storage
  (`--endpoint`, `--region`, TLS options in config); 256-bit password generated by moss and
  stored in the OS credential store (`--credential-store keyring|env`); 24-word BIP39 recovery
  sheet with a hard acknowledgement gate (`--recovery-acknowledged` under `--non-interactive`,
  `--print`); second-machine bootstrap by recovery code alone; profile identity (`--identity`);
  source discovery written to `config.yaml`; S3 keys taken from `AWS_*` or a prompt and persisted
  by Kopia under moss's state directory.
- `init list-backup-endpoints`: static, cited table of S3-compatible vendors (`--name`).
- `doctor`: Kopia found and in range; repository reachable; credentials and credential store
  (sentinel write and read); Kopia config file mode; recovery acknowledged; macOS Full Disk Access
  by `EPERM` probe and a launchd session warning; state directory; YubiKey placeholder; scan index
  age. Non-zero on any failure; `--json`.
- `inspect`: per-source and per-category sizes, sensitive counts (metadata only), exclusions by
  kind, the mandatory Skipped block with reasons, recorded collisions, guardrail warnings, scan
  index age. `--rescan`, `--measure-excluded`, `--estimate`, `--all`. Works offline.
- `backup`: moss-level lock (exit 10); recovery and sensitive-data gates (13 and 6); guardrails
  (`--yes`); manifest written and snapshotted with the run; one Kopia snapshot per source, all
  tagged `moss-run`/`moss-profile`/`moss-source`/`moss-os`/`moss-schema`; exclusions translated
  into per-source Kopia ignore rules; completeness read from `rootEntry.summ.numFailed` and
  `numIgnoredErrors`, never from Kopia's exit code; exit 9 on any skipped path. `--dry-run`,
  `--json`.
- `snapshots`: Kopia snapshots grouped into runs with a STATUS column (`complete`,
  `partial (n skipped)`, `incomplete (no manifest)`); `--host`, `--latest`, `--json`.
- `restore`: selector `latest` or run-id prefix; `--from-host`, `--category`, `--source`;
  two-stage restore into a moss-owned staging directory, then placement through per-OS
  containment primitives (Linux `openat2` `RESOLVE_IN_ROOT`, macOS `O_RESOLVE_BENEATH`, Windows
  component walk with volume-serial and file-index check); `--conflict
  skip|overwrite|backup|interactive`; collisions fail loudly unless `--rename-collisions`; write-ahead
  journal with `--resume` and `--rollback`; `--to <dir>`; cross-platform semantic path mapping
  (`video` to `~/Movies` or `~/Videos`, `user_home` to the destination user's home); post-restore
  report of embedded absolute paths that will not resolve.
- `status`: repository, credential source, Kopia unique id, maintenance owner and next full
  maintenance, latest run per host.
- `verify`: `kopia snapshot verify` over a run (`--files-percent`); `--check-modes` for
  `~/.ssh/*`, `~/.aws/credentials`, `~/.kube/config`, `~/.docker/config.json` (exit 8).
- `prune`: wraps `kopia snapshot expire --all`; `--delete` with confirmation or `--yes`.
- `maintenance`: wraps `kopia maintenance run --safety=full` (`--full`); warns when this machine
  is not the maintenance owner. `--safety=none` is never used.
- `config show|path`, `include <path> [--category]`, `exclude <path or pattern>`,
  `recovery show`, and the `kopia` escape hatch that runs Kopia with moss's config file and
  credentials.
- Profile discovery: macOS user-template directories with a `~/Library` allowlist and opt-in
  Containers, Application Support and Downloads (`moss include` by path turns an opt-in source
  on); k9s state as a `k9s` source on every platform; Linux XDG user directories with localised names resolved from `user-dirs.dirs`,
  `/etc/xdg/user-dirs.defaults`, then English; Windows known folders via `SHGetKnownFolderPath`.
  Every path is verified to exist before it becomes a source.
- Exclusions as gitignore-style patterns evaluated during the walk: build and dependency
  directories at any depth, known cache locations, tool-reported cache paths (`pip`, `pnpm`, `go`,
  `npm`, `yarn`, `uv`, two-second timeout, cached for a day), cloud-drive roots, Docker Desktop VM
  images, temporary files, moss's and Kopia's own state.
- Scan index with per-directory mtime reuse; parallel walk; fixed-rate progress that degrades off
  a TTY; `NO_COLOR` and `--quiet` honoured.
- Collision detection at backup time: case, Unicode normalisation, Windows-illegal names
  (reserved device names with any extension, including `COM0`/`LPT0` defensively, trailing dots
  and spaces, illegal characters), paths over 260 characters.
- Sensitive-file classification by path, name and extension: SSH, AWS, GPG, Kubernetes, Docker,
  cloud-provider, Git credential, password-manager export, API token, `.env`, credential cache,
  TLS private key.
- Kopia process hygiene: single command builder, explicit environment allowlist,
  `KOPIA_CHECK_FOR_UPDATES=false`, `--config-file` under moss's state, `--no-persist-credentials`,
  `--no-use-keychain`, `--disable-file-logging` unless `--verbose`, `--cache-directory` and
  `--no-check-for-updates` on connect; version pin 0.23.0 to 0.23.x with exit 11/12 and
  `--skip-version-check`; captured JSON fixtures for 0.23.1.
- Exit codes 0 to 13 as documented in `docs/exit-codes.md`; `--json` error objects.
- Global flags: `--config` (`MOSS_CONFIG`), `--profile` (`default` only), `--repository`,
  `--json`, `--quiet`, `--verbose`, `--dry-run`, `--non-interactive`, `--skip-version-check`.
  There is deliberately no `--password` flag.
- Documentation: README, ARCHITECTURE, SECURITY, CONTRIBUTING, `docs/exit-codes.md`,
  `docs/json-schema.md`, `docs/assumptions.md`, `docs/kopia-compat.md`.

### Planned (Phase 2)

Reserved command names print "not available in this version" rather than being unknown.

- YubiKey-protected repository password via an `age` envelope stored next to the repository
  (`moss yubikey setup|remove`; `detect` and `status` exist and report nothing configured).
- `moss upload` and `moss backup --local-only`: offline backup to a local copy and deferred
  `kopia repository sync-to` to S3, once the sync-to assumption in `docs/assumptions.md` is
  validated.
- `moss restore --rewrite-paths` with real per-format parsers for `~/.ssh/config`,
  `~/.gitconfig`, `~/.kube/config`, `~/.aws/config`, shell rc files and `~/.docker/config.json`.
- Named profiles (`moss profiles`, `--profile <name>`).
- Richer application-state discovery, more restore selectors, better size estimation, repository
  health checks, richer JSON, shell completions.
